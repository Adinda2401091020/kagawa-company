# Bengkel Las Kagawa — Company Website

Versi awal website company profesional, dibuat dari nol.

## Struktur
- `index.html` — halaman utama
- `assets/style.css` — seluruh styling + responsive layout
- `assets/main.js` — mobile navigation + active section
- `assets/README.txt` — catatan project

## Sebelum production
Ganti data placeholder berikut:
1. Nomor WhatsApp pada `index.html`
2. Alamat/lokasi detail
3. Jam operasional
4. Foto placeholder dengan foto project/workshop asli
5. Profil dan layanan sesuai data client
6. Tambahkan domain dan favicon/logo resmi jika tersedia

## Preview
Buka `index.html` langsung di browser.

## Catatan
Foto saat ini menggunakan remote Unsplash untuk keperluan desain/prototype. Untuk website production, sebaiknya diganti dengan dokumentasi asli Bengkel Las Kagawa agar identitas company lebih kuat dan tidak bergantung pada foto stok.
